# Calculator App

## Project Description

This project is a basic calculator app built using Kotlin/Jetpack Compose in Android Studio. The calculator supports standard arithmetic operations along with two additional tested features for assignment purposes.

## Calculator Features

-Addition
-Subtraction -Multiplication
-Division
-Squaring
-Backspace
-Decimal number input

## Tested Features
Clear button to reset the calculator
Delete button to remove the last entered character
Square (x²) function
Sign Change (+/−) function
Visual/Color Enhancements

## Function Instructions
1. Square (x²)
The square button allows the user to multiply the currently entered number by itself.
Example: 5 → x² → 25

2. Sign Change (+/−)
The sign change button allows the user to switch the currently entered number between positive and negative values.
Example: 5 → +/− → -5

Pressing the button again changes the number back to positive.

## Tech Used

Kotlin
Jetpack Compose
Android Studio
Gradle

## How to Run the Application
-Download the repository as a ZIP file.
-Extract the ZIP file.
-Open the project folder in Android Studio.
-Allow Gradle to sync.
-Run the application on an Android emulator or compatible device.
Alternatively, install the included app-debug.apk file on an Android device that permits APK installation.

## APK
The debug APK is included in the repository as app-debug.apk.
